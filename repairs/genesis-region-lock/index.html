Play imported games: Genesis and Mega Drive region lock

Genesis region locking has a software layer and a physical layer. Knowing which one you hit tells you whether an adapter, a Game Genie or a console mod is the right answer.

You are in the right place if: An import cartridge will not fit, or fits but shows a region error or a blank screen.

Before you start

  • Do not file cartridge shells or force them into the slot.
  • Region mods involve opening the console and soldering. Follow a specific guide for your board.

Step by step

  1. Look at the cartridge Many Japanese games will not physically fit a Genesis or PAL Mega Drive.
  2. Decide if it is physical or software If the cartridge fits but refuses to run, it is a software check.
  3. Check your console for TMSS Some motherboards have Trademark Security System hardware that blocks improperly formatted games.
  4. Try a region adapter A cartridge adapter can bypass the software check and sometimes help with fit.
  5. Try a Game Genie It can bypass region-checking code on some games.
  6. Consider a region mod A console modification disables the region check entirely.
  7. Test and keep a notes list Keep track of which games run and which need which workaround.
