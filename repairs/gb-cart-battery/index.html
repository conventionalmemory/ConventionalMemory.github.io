Repair guide

Replace the save battery in a Game Boy, Game Boy Color or GBA cartridge

Saving games use a small coin cell on the cartridge board. When it dies, saves are lost, so swap it before it does.

Battery · Medium · about 30 minutes. Try it, but check first. This will not fix every machine, so read the sources first.

You are in the right place if: A game starts a new file every time, or your progress vanishes after switching off.

Before you start

  • Do not solder directly to a bare lithium cell for long.
  • If there is leakage, clean it with the ConsoleMods process before fitting a new cell.

Board revisions and models

Cell type varies by game, so check your own cartridge. I did not find a source listing sizes per game, so treat that as unconfirmed.

Step by step

  1. Confirm the game has a battery Open it and look for a coin cell on the board, or check the game's title against a list of battery games.
  2. Back up the save if you can A cartridge reader lets you copy it. Otherwise assume the save may be lost during the swap.
  3. Open the cartridge Use the correct security bit for the shell.
  4. Photograph the battery and tabs Note which way it faces.
  5. Read the battery type Cell sizes vary between games. Check what is printed on yours, and replace like with like.
  6. Remove the old cell Snip or desolder the tabs. Clean any leakage.
  7. Fit the new cell Solder a battery with tabs, or a holder, with a quick touch of the iron.
  8. Test the save Start the game, save, power off and on again.
