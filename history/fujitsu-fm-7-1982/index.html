Fujitsu FM-7 (1982)

Fujitsu's 8-bit home computer for the Japanese market, notable for using two Motorola 6809 CPUs. It sold for about $500.

8-bit Japanese home computer using two 6809 CPUs, one for the main system and one for graphics and sub-system work.
