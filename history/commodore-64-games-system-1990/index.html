Commodore 64 Games System (1990)

A keyboardless C64C repackaged as a cartridge console; also called the C64GS. A near-total flop.

Released in December 1990 at 99 pounds, it omitted the user port, serial and cassette ports and so could not run most existing C64 software. Roughly 20,000 were built and about 2,000 sold. It shipped with a four-game cartridge and a Cheetah Annihilator joystick, and Ocean supported it with conversions such as Lemmings and RoboCop 2.
