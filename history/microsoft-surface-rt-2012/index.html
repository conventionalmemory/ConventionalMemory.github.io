Microsoft Surface RT (2012)

Microsoft's first self-designed PC, announced in June 2012 and released October 26, 2012 with Windows RT and a Tegra 3 ARM chip.

10.6 inch ARM tablet with a built-in kickstand and an optional Touch Cover keyboard.
