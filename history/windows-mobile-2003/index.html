Windows Mobile 2003 (2003)

The first release under the Windows Mobile name, launched on June 23, 2003 on the Windows CE 4.2 kernel. It unified the Pocket PC and Smartphone lines.

Merged Pocket PC and Smartphone branding on Windows CE 4.2.
