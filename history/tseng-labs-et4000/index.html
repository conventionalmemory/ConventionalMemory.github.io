Tseng Labs ET4000 (1989)

The SVGA chipset that was the DOS gamer and Windows 3.x favorite from about 1990 to 1995.

Its host interface was unusually fast for ISA, so it beat rivals in DOS and early Windows. Cards from Diamond, Orchid, Hercules and others used it, and the ET4000/W32 variant added Windows acceleration.
