Tandy Video Information System (VIS) (1992)

A Radio Shack CD-ROM set-top console running Modular Windows, aimed at educational and reference software.

An 80286 at 12 MHz with 1 MB RAM and a 1x CD drive, it ran Modular Windows, a Windows 3.1 variant used on no other product. Radio Shack sold only 11,000 units before dropping it in early 1994, and staff joked VIS meant Virtually Impossible to Sell. Software was almost entirely children's and reference titles.
