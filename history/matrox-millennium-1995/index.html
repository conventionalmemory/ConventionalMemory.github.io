Matrox Millennium (1995)

Matrox's celebrated 2D Windows accelerator, loved for image quality.

The Millennium was the 2D speed champion of the Windows 95 era and a favorite for CAD and desktop publishing. Gamers paired it with a Voodoo add-on.
