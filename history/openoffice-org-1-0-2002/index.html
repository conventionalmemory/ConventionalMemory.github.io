OpenOffice.org 1.0 (2002)

The first stable OpenOffice.org release, on May 1, 2002, for Windows, Linux and Solaris. It grew out of the StarOffice source code that Sun released in October 2000.

Free and open source office suite alternative to Microsoft Office.
