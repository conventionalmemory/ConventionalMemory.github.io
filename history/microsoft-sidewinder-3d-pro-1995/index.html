Microsoft SideWinder 3D Pro (1995)

Microsoft's first SideWinder flight stick, with twist rudder.

Digital overlay on the game port gave precise reads and the twist handle acted as rudder, targeting Windows 95 and DirectX. Launched with Windows 95.
