R.O.B. (Robotic Operating Buddy) (1985)

Nintendo robot accessory released in Japan on July 26, 1985 and in North America on October 18, 1985. It was bundled in the NES Deluxe Set with Gyromite.

R.O.B. shipped in the NES Deluxe Set with the Control Deck, Zapper, Gyromite and Duck Hunt. It was later sold separately for 49.99 dollars.
