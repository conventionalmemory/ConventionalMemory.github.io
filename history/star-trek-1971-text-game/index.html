Star Trek (1971 text game) (1971)

Mike Mayfield wrote this text strategy game on an SDS Sigma 7 while in high school. It spread to mainframes across the US by 1975.

Created in 1971 for the SDS Sigma 7. It reached many ports through 101 BASIC Computer Games.
