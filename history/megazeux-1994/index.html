MegaZeux (1994)

Alexis Janson's DOS game-creation system, first sold as shareware on December 4, 1994 with the adventure Zeux II: Caverns of Zeux. A spiritual successor to ZZT.

MegaZeux debuted as shareware for DOS on December 4, 1994, distributed through AOL along with the adventure Zeux II: Caverns of Zeux. Like ZZT before it, the world editor was free, so anyone could build games without paying. It improved on ZZT with independently chosen foreground and background colors for every character, editable character sets, custom color palettes and MOD music. Games were scripted with robots in a language called Robotic, first named Robo-P, which grew subroutines, counters and expressions. The author released all the games and the source code freely in 1998, and the community has kept it alive since under the GPL on Windows, macOS, Linux, DOS, consoles and in a web browser.
