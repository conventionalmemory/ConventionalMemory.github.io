Intel Above Board (1984)

A famous expanded-memory board for breaking the 640 KB limit.

The Above Board carried up to several MB of bank-switched RAM and supported Lotus/Intel/Microsoft EMS. Spreadsheets like Lotus 1-2-3 used it for very large worksheets. RAM then cost hundreds of dollars per MiB, so it was a pricey upgrade.
