Intel Sandy Bridge (2nd generation Core) (2011)

Intel's second-generation Core processors, announced at CES in January 2011, with an integrated graphics unit on the same die as the CPU.

Sandy Bridge, such as the Core i7-2600K, used the LGA 1155 socket.
