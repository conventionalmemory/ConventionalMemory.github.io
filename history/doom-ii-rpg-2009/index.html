Doom II RPG (2009)

Sequel to Doom RPG for Java ME, BlackBerry, Windows Mobile and iOS. Java ME edition November 23, 2009.

Directed and produced by Katherine Anna Kang. Metacritic aggregates 80/100 and IGN gave 8/10. The iOS version can run today through the touchHLE emulator.
