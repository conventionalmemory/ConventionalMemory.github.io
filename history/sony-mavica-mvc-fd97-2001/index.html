Sony Mavica MVC-FD97 (2001)

10x zoom floppy Mavica with a Memory Stick slot.

The FD97 added a Memory Stick slot to the 4x speed floppy drive and a 10x optical zoom. Wikipedia likens it to the MVC-CD1000.
