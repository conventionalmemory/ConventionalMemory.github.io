Hunt the Wumpus (1973)

Gregory Yob's text game was first mentioned in the People's Computer Company newsletter in September 1973, with a two-page description in November 1973. Source code appeared in Creative Computing in October 1975.

Written in BASIC and later ported to many systems, including the TI-99/4A.
